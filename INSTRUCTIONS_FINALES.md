## 📱 COMMENT SYNCHRONISER VOS DONNÉES :

### Sur PC :
1. Ouvrez l'application
2. En bas de page, cliquez **"📤 Exporter mes données"**
3. Un fichier `.json` sera téléchargé

### Sur téléphone :
1. Transférez le fichier `.json` sur votre téléphone (email, Drive, WhatsApp...)
2. Ouvrez l'application sur le téléphone
3. En bas de page, cliquez **"📥 Importer des données"**
4. Sélectionnez le fichier `.json`
5. Rechargez la page → ✅ Vos données apparaissent !

### Inversement (téléphone → PC) :
1. Sur téléphone : **"📤 Exporter"**
2. Transférez le fichier vers PC
3. Sur PC : **"📥 Importer"**
